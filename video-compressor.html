OVERVIEW

Compression by target file size

I built this AI-assisted PowerShell project to simplify sharing videos through Discord, email, and other services with upload size restrictions. Instead of selecting an arbitrary quality setting, users enter their desired file size in MB and the application calculates the video and audio bitrates.

Target-size encoding

FFprobe reads video duration, then the application calculates a bitrate budget based on the requested size and an encoding safety margin.

Hardware acceleration

Tests available hardware encoders for NVIDIA NVENC, Intel Quick Sync, and AMD AMF. If a GPU encode fails, the application can retry using the CPU.

Windows GUI

Provides drag-and-drop input, output selection, format controls, a progress bar, cancel functionality, and a live log.

Output protection

Encodes to a temporary file, promotes the result only after successful encoding, and requests confirmation before replacing an existing output.

ENCODING ENGINE

Balancing speed and file size

CPU encoding

Two-pass H.264 or VP9 encoding allocates the available bitrate across the video and uses a 5% safety margin. WebM uses the CPU.

GPU encoding

Single-pass hardware H.264 encoding uses capped variable bitrate with an 8% safety margin. Users can choose Force CPU and optionally downscale to 720p without upscaling smaller videos.

DISTRIBUTION

Installer and desktop deployment

The project includes an Inno Setup configuration, custom application icon, license agreement, and a compiled Windows installer. FFmpeg and FFprobe are bundled with the installer, and the setup creates Start Menu and optional desktop shortcuts.

Local processing

The application processes selected video files on the Windows computer instead of relying on a cloud compression service.

Troubleshooting support

Error messages, a live progress log, and a local error log help diagnose invalid inputs and encoding failures.
