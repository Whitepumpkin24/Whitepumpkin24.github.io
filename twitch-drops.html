Twitch Drops Tag Estimator

A Discord notification service that estimates possible Drops activity by counting Drops-related tags on live Twitch streams. It does not verify active Drops campaigns or reward eligibility.

OVERVIEW

Discovering possible Twitch Drops activity

I built this AI-assisted integration for Pumpkin's Spy so community members can quickly discover game categories where live streamers are using Drops-related tags. It summarizes results in a Discord embed and links to the Twitch Drops campaigns page.

Game category discovery

Resolves configured game names to exact Twitch categories and queries live streams through the Helix API.

Scheduled and manual reports

Posts a daily check at 8:00 AM Philippine time and supports the !dropcheck command in the configured channel.

OAuth integration

Uses Twitch application authentication, reuses access tokens and refreshes authentication when necessary.

Request management

Uses a manual-command cooldown, shares in-progress scans, and reports errors by game category.

DEPLOYMENT

Containerized service

Docker Compose

The included configuration uses Node.js 22 Alpine, locked production dependencies, and a restart policy.

Container safeguards

Runs as a non-root user with a read-only filesystem, no-new-privileges setting, temporary storage and bounded log files.

The notifier uses the same Pumpkin's Spy Discord identity as my giveaway and content scanner integrations. Private credentials are kept in environment configuration and excluded from this portfolio.
