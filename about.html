REAL-WORLD CASE STUDIES

Problems I've helped resolve

VLAN mismatch

Problem: A user could not access required websites.

Investigation: Compared endpoint addressing and DHCP records, then identified the switch port and VLAN using CDPwin.

Outcome: Provided precise evidence to the network team for correction of the VLAN assignment.

Site-wide printer outage

Problem: Printers throughout the building were unavailable after losing reserved DHCP addresses.

Investigation: Identified changed printer addresses and restored reservations, then reconciled print server queues and drivers.

Outcome: Printers were restored and mapped to their proper floors and departments.

Persistent Outlook session errors

Problem: Outlook web and desktop failed while other Microsoft 365 applications worked.

Investigation: Tested profiles, credentials and devices, then escalated to the Microsoft 365 team.

Outcome: Suggested a license reassignment that the team implemented; Outlook access was restored with the mailbox intact.

Examples are summarized without confidential client or employee information.
